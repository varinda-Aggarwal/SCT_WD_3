# SCT_WD_3 - Quiz Game Application

An interactive quiz web application built during my Web Development Internship at SkillCraft Technology. The app lets users practice topic-wise coding and CS questions with real-time feedback, progress tracking, and a personal dashboard.

# Task Description
Develop an interactive multiple-choice quiz game that:
- Displays questions and collects answers
- Provides a score at the end
- Supports different question types

# Technologies Used
- HTML
- CSS
- JavaScript (Vanilla)

# Features
- Multiple choice questions across CS topics
- Practice mode and timed Test mode
- Difficulty levels — Easy, Medium, Hard
- Real-time score tracking
- Result screen with answer review
- Personal dashboard with topic progress
- Recent activity history
- Daily goals tracker
- Dark / Light mode toggle
- Fully responsive design

# Project Structure
SCT_WD_3/

├── topic-select.html  → Topic selection
